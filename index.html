My Systems

Seven tools built for one port office. Open the details to see the problem each one solves, or jump straight into a working demo with sample data.

About this portfolio

Each system started from a paper process that someone was already doing by hand.

Built around real office paperwork

Logbooks, RMR forms, survey sheets, ICS and PAR records, training files. Every system starts from a form someone was already filling in by hand.

Works where the office works

Most run offline from a single folder or file. The phone apps run on Google Workspace, so nothing needs installing.

Made with help from Claude

I designed and tested all seven systems. They were built with the help of Claude, an AI assistant from Anthropic, and so was this page.

Demos use sample data

Names, property numbers and records in the demos are made up. Real office records are not part of this page.

How each system works

The problem, what it does, and what it gives the office.

Technologies used

Everything across the seven systems, from plain browser code to Google Workspace and AI vision.

Want a tool like these for your office?

Most of these started as a small request: "can we stop retyping this?" If your unit has a paper process that repeats every week or every month, it can probably be automated.
